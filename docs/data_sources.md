# Data Source Assessment

**Project:** MLS Recruitment Intelligence  
**Purpose:** Choose reproducible, legally/practically usable sources before building scrapers.  
**Last updated:** 2026-07-23

## Decision summary (MVP)

| Priority | Source | Use | Method |
| --- | --- | --- | --- |
| **Primary** | American Soccer Analysis (ASA) API via `itscalledsoccer` (R) | Player/team identity, xG, xPass, Goals Added, MLS salaries, games | Official public API — **no custom scraper** |
| Secondary | FBref via `worldfootballR` (optional later) | Broader leagues (CPL, NCAA gaps), traditional Opta-style tables | Rate-limited package wrappers; cache aggressively |
| Contextual | MLSPA Salary Guide / ASA salaries | Guaranteed compensation | Prefer ASA salaries endpoint; MLSPA as validation |
| Avoid as core | Transfermarkt scraping | Market values / transfers | Terms-restricted; use only contextual manual tiers if needed |
| Demo | Synthetic cohort in `data/external/demo/` | End-to-end reproducibility without network | Generated by `scripts/00_generate_demo_data.R` |

**Do not build the project around a fragile custom HTML scraper.** Prefer APIs and maintained R packages, cache responses, and record retrieval timestamps.

## 1. American Soccer Analysis (ASA)

| Dimension | Assessment |
| --- | --- |
| **Leagues** | MLS, MLS NEXT Pro (`mlsnp`), USL Championship (`uslc`), USL1, USLS, NWSL, historical NASL |
| **Seasons** | Multi-season; API accepts `season_name` filters (MVP uses 2023–2025) |
| **Metrics** | xGoals, xPass, Goals Added (g+) by action type, salaries (MLS), shots/games endpoints |
| **Update frequency** | In-season updates aligned with ASA app (treat as near-regular; always cache) |
| **Player identifiers** | Stable ASA `player_id` / `team_id` — excellent for relational joins |
| **Licensing / usage** | Public API, free, no key required. Attribute ASA. Confirm current terms before commercial reuse. |
| **Scraping difficulty** | **None** if using API / `itscalledsoccer` |
| **Reliability** | High for North American leagues; metrics are model-based (xG/g+) — document as estimates |
| **Fit to research question** | **Best MVP source** — covers realistic recruitment markets + salaries |

### R access pattern

```r
library(itscalledsoccer)
asa <- AmericanSoccerAnalysis$new()
xg <- asa$get_player_xgoals(leagues = "mls", season_name = 2025, split_by_seasons = TRUE)
sal <- asa$get_player_salaries(leagues = "mls", season_name = 2025)
```

API docs: https://app.americansocceranalysis.com/api/v1/__docs__/  
R client: https://american-soccer-analysis.github.io/itscalledsoccer-r/

### Gaps relative to this project

- Limited explicit “pressures” / some FBref defensive detail depending on endpoint  
- Contract expiry / transfer fees generally **not** available  
- Canadian Premier League / NCAA not covered  
- g+ action types must be unnested carefully for role metrics  

**Mitigation:** Map available ASA fields to role proxies; impute missing role metrics with neutral priors + higher risk; extend later with FBref for specific metrics.

## 2. FBref (+ `worldfootballR`)

| Dimension | Assessment |
| --- | --- |
| **Leagues** | MLS, USL Championship, many international; CPL/NCAA coverage varies |
| **Seasons** | Deep historical for major comps |
| **Metrics** | Standard, shooting, passing, GCA, defense, possession, misc — richer raw counting stats |
| **Update frequency** | Match/season pages; scraping must pause between requests |
| **Player identifiers** | FBref player IDs / URLs — need crosswalk to ASA IDs |
| **Licensing / usage** | Respect robots.txt, terms, and Sports Reference policies; attribute FBref/Opta |
| **Scraping difficulty** | Medium — use `worldfootballR`, `time_pause`, local cache; avoid hammering |
| **Reliability** | High for published tables; breaking HTML changes are a maintenance risk |
| **Fit** | Strong **extension** source; not required for MVP if ASA covers pool |

**Policy in this repo:** Optional collector behind a feature flag. Never tight-loop scrape. Prefer downloadable tables when offered.

## 3. MLS Players Association (MLSPA) Salary Guide

| Dimension | Assessment |
| --- | --- |
| **Leagues** | MLS only |
| **Seasons** | Semi-annual releases (spring/fall), PDF/HTML historically |
| **Metrics** | Base salary, guaranteed compensation, club, position |
| **Currency** | **USD** for all clubs (including Canadian MLS sides). Stored as `salary` / `salary_usd`; UI labeled USD. Non-USD inputs converted via FX. |
| **Identifiers** | Name + club (fuzzy match required) |
| **Licensing** | Public salary guide; attribute MLSPA; do not claim official partnership |
| **Scraping difficulty** | Medium (HTML/PDF parsing); prefer ASA salaries when equivalent |
| **Reliability** | High for listed contracts as of release date; stale between releases |
| **Fit** | Essential for financial value / feasibility tiers |

**MVP approach:** Use ASA `get_player_salaries` first; keep MLSPA as cross-check documentation.

| **MVP policy** | **Do not scrape.** Use manual/estimated cost tiers or user-entered values. Document uncertainty. |

| Source | Notes |
| --- | --- |
| USL public stats | Prefer ASA `uslc` endpoints over site scraping |
| Club roster pages | Fragile; use only for spot validation |
| NCAA stats | Fragmented; high identity-matching cost; Phase 2+ |

## 7. Kaggle

Use **only** when the original upstream source and license are clear. Prefer pulling from ASA/FBref directly for reproducibility.

---

## Identity matching strategy

1. Prefer native ASA `player_id` within ASA-covered leagues.  
2. Maintain `player_identity_keys` (normalized name, DOB if available, approximate age, primary nationality).  
3. Fuzzy match salaries and any FBref rows with manual review flags (`match_confidence`).  
4. Never silently merge low-confidence identities into rankings without a data-quality penalty.

---

## Caching & reproducibility rules

- Cache raw API responses under `data/raw/cache/` with `retrieved_at` timestamps.  
- Record `data_sources` rows in SQL for every load.  
- Default `project.mode: demo` for offline CI / portfolio demos.  
- `project.mode: live` for ASA pulls with `pause_seconds` ≥ 1.
